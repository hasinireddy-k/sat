# [SECTION 3: MULTI-SPECTRAL & SAR SENSOR PROFILES]
# Sentinel-2 Bands:
#   B01 (443 nm, 60m): Coastal aerosol, atmospheric correction
#   B02 (490 nm, 10m): Blue - Water penetration, soil/veg discrimination
#   B03 (560 nm, 10m): Green - Peak vegetation reflectance
#   B04 (665 nm, 10m): Red - Chlorophyll absorption
#   B05 (705 nm, 20m): Red Edge 1 - Chlorophyll content
#   B06 (740 nm, 20m): Red Edge 2 - Leaf area index
#   B07 (783 nm, 20m): Red Edge 3 - Canopy structure
#   B08 (842 nm, 10m): Broad NIR - Biomass, cellular structure
#   B8A (865 nm, 20m): Narrow NIR - Water vapor absorption correction
#   B09 (945 nm, 60m): Water vapor absorption
#   B11 (1610 nm, 20m): SWIR-1 - Soil moisture, snow/cloud discrimination
#   B12 (2190 nm, 20m): SWIR-2 - Vegetation moisture, mineral detection
# Sentinel-1 SAR Dual-Pol (C-Band, 5.405 GHz):
#   VV: Vertical transmit, Vertical receive - Surface roughness, water boundary delimitation
#   VH: Vertical transmit, Horizontal receive - Volume scattering from forest canopy / vegetation structure
